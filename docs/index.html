Projetos Acadêmicos

HypScrum

Primeiro semestre

Este projeto é um sistema web desenvolvido para guiar os usuários no aprendizado do Scrum. O sistema inclui seções de instrução com avaliações e um mecanismo para emissão de certificados de conclusão do curso. Ele é construído utilizando HTML, CSS, JavaScript e PostgreSQL, e as telas foram prototipadas no Figma.

Participação: Atuei na prototipação, no levantamento de materiais e no desenvolvimento do projeto, contribuindo também para a padronização das telas e garantindo consistência na interface.

HypoHeat

Segundo semestre

É uma aplicação web que permite aos usuários acessar informações sobre áreas queimadas, risco de fogo e focos de calor do Programa Queimadas do INPE. A aplicação conta com gráficos e mapas interativos, além de funcionalidades para aplicação de filtros personalizados.

Participação: Atuei como Scrum Master, garantindo que o time seguisse corretamente o processo e entregasse resultados de qualidade, e também como desenvolvedora, contribuindo diretamente no desenvolvimento de funcionalidades e soluções do projeto com foco no Front-End.

HypoOrbit

Terceiro semestre

HypoOrbit é uma aplicação web que centraliza buscas de dados e imagens de satélite gratuitas e permite gerar produtos derivados úteis para análise agrícola, como o NDVI (Índice de Vegetação por Diferença Normalizada) e o VCI (Índice de Condição da Vegetação).

Participação: Atuei como Product Owner, organizando features e user stories, definindo o escopo de cada sprint e estruturando o Sprint Backlog para garantir clareza sobre o que deve ser realizado em cada tarefa. Além disso, atuando também como desenvolvedora Front-End, participando da implementação das funcionalidades e melhorias do projeto.

HypoHealth

Quarto semestre

HypoHealth é um sistema inteligente de gerenciamento e dispensação de medicamentos que integra Internet das Coisas (IoT) e uma aplicação móvel . A solução foi projetada para auxiliar no controle específico de tratamentos, garantindo que o medicamento correto seja acessado apenas no horário programado, evitando erros de dosagem e esquecimentos. O foco principal do projeto é promover a autonomia de pacientes , especialmente idosos com doenças crônicas, e oferecer segurança e tranquilidade aos familiares e cuidadores por meio do monitoramento remoto em tempo real.

Participação: Atuei como desenvolvedora Front-End, Back-end e na parte de Hardware, pensando na melhor solução para ter uma boa usabilidade, inclusivo e funcionar corretamente o sistema e produto físico.
